# The Watch Gallery

**The Watch Gallery** is a front-end e-commerce website for browsing and purchasing watches, developed using **HTML, CSS, and JavaScript**. The project simulates a complete online shopping experience without requiring a backend or external database.

### Features

* User registration and login with role-based access (`user` / `admin`)
* Dynamic navigation based on authentication status
* Browse watches by category
* Search functionality for products
* Add, remove, and manage items in the shopping cart
* Dummy payment/checkout system
* Order history and order tracking
* Admin dashboard for managing products and orders
* Admin can add and remove watches
* Admin can view registered users and customer orders
* Admin can update order status: **Paid, Processing, On the Way, Delivered**
* Responsive and user-friendly interface
* Browser `localStorage` used to simulate database functionality
* Watch images integrated using Unsplash

### Technologies

**HTML5 | CSS3 | JavaScript | LocalStorage**

> This project is a front-end simulation of an e-commerce platform. MongoDB and real payment processing are not used because the application is designed as a client-side-only project.
